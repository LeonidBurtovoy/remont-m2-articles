# Ремонт М2 — банк материалов для ежедневного автопостинга

`articles.md` содержит 225 статей по темам ремонта квартир и домов в Калининградской области. Каждая статья начинается с заголовка `## N. Название` и продолжается до следующего `## N.` или до `---`.

Используется ежедневным роутином, который постит по одной статье в день в канал https://t.me/m2remontm2 в 8:00 по Калининграду.

Логика выбора статьи на конкретный день — детерминированная, без внешнего состояния: `номер = ((дни с даты старта) % 225) + 1`, дата старта и точная формула — в промпте роутина.

Банк пополнялся партиями: 1–145 (старт), 146–175, 176–225. Все статьи также опубликованы в блоге сайта: https://remont-m2.ru/blog

## Что лежит рядом со статьями

| Папка или файл | Что внутри |
| --- | --- |
| `images/` | три карточки 1080×1080 на каждую статью: `NNN-cover`, `NNN-lifehack`, `NNN-summary` — 675 файлов |
| `videos/` | вертикальный ролик 1080×1920 на каждую статью, 11,6 с, со звуком — 225 файлов |
| `links.json` | номер статьи → её адрес в блоге, чтобы посты вели на конкретный материал |
| `vk/post_vk.py` | публикация статьи дня на стену сообщества ВКонтакте |
| `vk/post_clip.py` | публикация ролика дня в клипы сообщества ВКонтакте |

Ролик и статья дня выбираются одной и той же формулой, поэтому в один день выходит один и тот же материал в двух форматах. `post_vk.py` после публикации поста сам вызывает загрузку ролика — отдельно запускать `post_clip.py` не нужно, и если ролик не загрузится, пост от этого не пострадает. Отключается флагом `--no-clip`.

## Запуск скриптов ВКонтакте

Нужны переменные окружения:

- `VK_TOKEN` — ключ сообщества, им публикуется сам пост;
- `VK_GROUP_ID` — числовой id сообщества;
- `VK_USER_TOKEN` — токен пользователя-администратора со scope `photos,video,wall,groups,offline`.

Третий обязателен для картинок и роликов: ключу сообщества ВКонтакте отказывает в
`photos.getWallUploadServer` и `wall.get` с ошибкой 27 «method is unavailable with
group auth», сколько прав ему ни выдай. Без `VK_USER_TOKEN` пост выйдет текстом,
а в выводе будет сказано почему.

```
python vk/post_vk.py   --check      # проверить ключ и права, ничего не публикуя
python vk/post_vk.py   --dry-run    # показать текст поста
python vk/post_clip.py --check      # проверить, доступны ли клипы этому ключу
python vk/post_clip.py --dry-run    # показать описание ролика
```

Без флагов скрипт публикует материал текущего дня. `--number N` берёт конкретный номер, `--force` снимает защиту от повторной публикации.

Клипы загружаются методом `shortVideo.create`. Если ключу он недоступен, скрипт сам откатывается на `video.save` — ролик ляжет в видео сообщества.
