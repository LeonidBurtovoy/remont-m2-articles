# Ремонт М2 — банк статей для автопостинга в Telegram

`articles.md` содержит 145 статей по темам ремонта квартир и домов в Калининградской области. Каждая статья начинается с заголовка `## N. Название` и продолжается до следующего `## N.` или до `---`.

Используется ежедневным роутином, который постит по одной статье в день в канал https://t.me/m2remontm2 в 8:00 по Калининграду.

Логика выбора статьи на конкретный день — детерминированная, без внешнего состояния: `номер = ((дни с даты старта) % 145) + 1`, дата старта и точная формула — в промпте роутина.
